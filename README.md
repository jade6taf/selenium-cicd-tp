#TP Guidé : Selenium

1. Avantages observés :

- Quels sont les avantages de l'automatisation des tests que vous avez constatés ?
L’automatisation réduit le temps de test, assure la répétabilité des scénarios et détecte rapidement les régressions.
- Comment le CI/CD améliore-t-il la qualité du code ?
Le CI/CD valide chaque commit avec des tests automatisés, permettant de livrer un code fiable et cohérent à chaque intégration.

2. Défis rencontrés :
- Quelles difficultés avez-vous rencontrées avec Selenium ?
Les principaux problèmes sont la synchronisation des éléments, la gestion des éléments dynamiques et les différences de rendu entre navigateurs.
- Comment pourriez-vous améliorer la stabilité des tests ?
En utilisant WebDriverWait, le pattern Page Object et en isolant les tests critiques pour éviter les dépendances.

3. Métriques :
- Quelles métriques sont les plus importantes pour votre projet ?
Le taux de réussite des tests, la couverture de code, le temps moyen de détection des bugs et le temps de build/déploiement.
- Comment mesurer l'efficacité de votre pipeline CI/CD ?
Par la fréquence des builds réussis, le temps moyen de livraison, le pourcentage de tests automatisés exécutés et le temps moyen de résolution des erreurs.
